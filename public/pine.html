Footprint Overlay

    Download .pine Guide

    Add it to TradingView

    1. Open a chart on TradingView and open Pine Editor at the bottom.
    2. Choose New → Indicator, select all of the template and delete it.
    3. Tap Copy code above and paste it into the empty editor.
    4. Click Save, then Add to chart.

    Copy from this page or use the downloaded file. Don't send the code through a chat app: messaging apps turn text such as 8) into emoji, which breaks the script.
